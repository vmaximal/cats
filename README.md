# Кошки

Учёт кошек, помётов и отцов.
Максимально просто: без composer, без docker, на sqlite

## Что нельзя

- Отцом может быть только самец, матерью - только самка.
- Отец не может быть котёнком того же помёта.
- Отец не может быть матерью того же помёта.
- Мать не может быть котёнком собственного помёта.
- Нельзя замкнуть круг: кошка не может оказаться потомком самой себя.
- У кошки, у которой есть помёт или отцы, нельзя поменять пол.
- Один кот не добавляется в отцы одного помёта дважды.
- Кличка - от 1 до 60 символов, порода - до 80, название помёта - до 60, возраст - от 0 до 30 лет.
- Мать у помёта одна, отцов - сколько угодно.

## Если удалять

- Удаляешь кошку - её помёты тоже удаляются, котята остаются, но без помёта.
- Удаляешь помёт - котята остаются, но без помёта.

## Запуск

1. Скачать [FrankenPHP](https://github.com/php/frankenphp/releases#release-v1.12.7) и положить бинарник в корень приложения.
2. Создать базу данных - `./frankenphp php-cli migrate.php`
3. Запустить - `./frankenphp run`
4. Открыть http://localhost:3000/
